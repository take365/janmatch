# JanMatch

オンライン麻雀大会の運営を支援するシステムです。

現在はローカルMVPとして、次の運営フローを画面上で確認できます。

- 大会名・パスワード・回戦数・制限時間・ルールの設定
- ニックネームによる参加者受付
- 参加者の参加／受付待ち切り替え
- 4人卓の仮組みと回戦進行
- 順位表と点数の仮入力
- 結果画像のAI読み取りを追加するための確認欄

## 起動

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:3000> を開きます。
